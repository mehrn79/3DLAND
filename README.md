# 3DLAND Project Page

This repository contains the source code for the 3DLAND dataset project website.

## Features
- **Responsive Design:** Based on Bulma CSS.
- **Academic Template:** Clean, readable, and professional.
- **Color Palette:** Inspired by the 3DLAND paper (Liver Orange, Soft Beige, etc.).

## How to use
1. Add your images to `static/images/`.
2. Update the `index.html` with your specific GitHub links and media.
3. Enable **GitHub Pages** in your repository settings.
